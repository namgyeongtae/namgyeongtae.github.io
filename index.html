Combo Cumulation Issue
❌ Problem

같은 곡을 시연할 때마다 같은 롱노트로부터 얻어지는 콤보의 수가 달라지는 현상 발생

🔎 Root Cause
  • 롱노트를 누르는 동안의 콤보 획득 로직을 프레임에 의존하는 Update 함수에서 계산한 것이 원인
  • 고정적인 콤보 수치가 아닌 프레임으로 콤보를 실시간으로 계산하게 되면서 때마다의 프레임 성능마다 얻어지는 콤보가 달라지는 것
✅ Solution

롱노트를 생성할 시 채보 데이터의 롱노트 지속 시간(Duration)과 간격(Combo Interval)을 설정해 사전에 먼저 해당 롱노트를 통해 얻어지는 고정적인 콤보 수 (TargetCombo)를 계산하여 롱노트가 딱 이 콤보 수 만큼만 판정되도록 수정하여 해결

📈 Result

롱노트로부터 얻어지는 콤보가 매 플레이마다 동일하게 누적

Combo Cumulation Issue
❌ Problem

Collider 충돌과 같은 물리적 연산에 의해 플레이어의 이동이 동기화가 되지 않는 현상 발생

🔎 Root Cause
  • 서로 다른 클라이언트 기기에서의 물리적인 연산까지는 네트워크를 통해 동기화가 되지 않기 때문
✅ Solution

맵을 2차원 배열로 표현하여 이동가능 영역 (0), 이동불가 영역(1)을 구분하여 현재 플레이어가 이동할 다음 타일이 어떤 영역인지 판단 후 이동 동기화에 반영하여 해결

📈 Result

이동 불가 영역은 아예 갈 수 없는 로직으로 설계되어 막히지 않고 이동 가능 영역만 이동 동기화에 반영되어 이동 가능
